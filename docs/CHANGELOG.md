# WorldLife Next 版本里程碑与工程变更

**来源**：参考 world-preview v0.5 的 World/Life 结构。新工程独立打包，并不声明可以直接替换原分支的全部文件和旧存档。

## v0.6 通用行动系统

- 用 `ActionRegistry` 和 `ActionHandler.prepare/complete` 拆分行为，避免持续增加 `WorldRuntime._dispatch()` 的专属分支。
- `ActionPlan` 支持多人行动的参与者占用。
- `action_ticket` 取消中断后遗留的完成事件，保证动作不会“被取消后再次结算”。
- 继承世界资源结算、局部观察和行动失败退避机制。

## v0.7 自主行为与简单目标

- 保留需求优先级、需求目标持续和逐段移动。
- 新增 `practice` 兴趣活动、简单承诺期限和长期技能目标。
- 实际完成练习后才更新技能和目标达成状态。
- 从角色当下观察建立 `known_edges`，不再依赖未到访地点的全局连边知识。

## v0.8 基础心理、社会认知与记忆

- 人格倾向影响部分社交和兴趣决策；短时情绪按时间衰减。
- 真实社交/帮助/失败事件形成情景记忆，关系随事件更新。
- 关系信任改成随接近边界减弱变化的机制，降低极端值固化风险。
- 新增简单中文/日文字符片段与英文单词的记忆检索。

## v0.9 可选 LLM 集成接口

- `CognitionService` 以角色可见数据生成上下文，支持 JSON 回复及行动建议。
- `OpenAICompatibleBackend` 使用标准库提供兼容 HTTP 集成。
- 每角色/模拟日的请求上限和失败回退；模型输出 JSON 白名单验证。
- `ScriptedBackend` 支持不联网的回归测试；真实远程 API 尚未验证。

## v1.0 最小多人世界与可复现实验

- 多人物共享世界、设施与资源，支持协助与社交互动。
- 多人行动占用避免对象在对话期间被调度离开，支持任一参与者中断。
- 58 项独立测试，5 个基准场景、30 组七日扰动与回放一致性检查。
- 自包含的 SQLite 实验数据、小时级 CSV、文档与一键验收脚本。

**版本号是当前教学/研究工程的里程碑，不表示完整通用虚拟人类系统已完成。** 具体未实现功能请参阅 `LIMITATIONS.md`。
