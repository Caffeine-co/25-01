# 版本与开发迭代

## 2.0.0 — 单机正式可用范围

### 多步骤自主规划
- `planning.py`：新增项目与项目步骤，可通过场景和 API 创建；真实执行证据、优先级、截止、退避重试、失败、取消。
- 项目可在熟悉的个人地图上自主逐步前往目标设施，不绕过物理动作。
- 紧迫需求仍优先，不被普通项目抢占；项目完成/失败均写入审计日志。

### 主观认知与主动 LLM
- `knowledge.py`：有来源、置信度、历史、同源防放大的个人信念。
- `cognition.py`：新增自发反思入口，结构化项目建议校验，模型提议无世界写权限；可设每日预算。
- 加强 `submit_intent` 个人知识过滤，拒绝未知设施和未知路线。

### 部署、并发和安全
- `store.py`：新增 checkpoint revision 校验、SQLite WAL、事务回执及请求幂等、在线 backup。
- `service.py`、`server.py`：单机 HTTP 服务、Bearer Token、自动时钟、原子变更和异常重载。
- `client.py`、`admin.py`：可直接使用的客户端和备份/检查工具。
- 模型兼容后端对非本地 HTTP URL 强制要求 HTTPS。

### 实验/修复
- 首次 HTTP 线程测试发现 SQLite `ProgrammingError`，已修复并加入串行锁。
- 多步骤项目在设施停用后失败、退避、重新成功的情境中完成实测。
- 发现一开始比对全程/续跑事件日志的口径不一致，已修正测试基准。
- 增加 51 项正式版测试，累计 109 项；新增 6 场景基准、60 种初值压力、HTTP 子进程 smoke。
