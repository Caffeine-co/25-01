# 工程验收记录

## 本次交付覆盖

**程序源文件**：可运行 Python 包 `simlife/`，`pyproject.toml` 配置，示例世界/人物/场景，扩展与测试脚本。

**测试产物**：自动化用例 `tests/test_simulation.py`、5 场景运行日志和数据库、每小时指标 CSV、30 组固定种子扰动结果、`results/verification.json`。

**文档产物**：README、架构、不变量、完整伪代码、真实运行流、实验报告、扩展指南、版本变化和能力边界。

## 验收指令

```bash
python scripts/verify.py
```

上述命令依次运行：58 项单元/集成测试、5 场景基准、30 组七日扰动、`compileall`，并输出 `results/verification.json`。依次全部返回退出码 0 为通过。

## 主要验收项

| 预期目标 | 结果 |
|---|---|
| 能在无 LLM、无平台连接时长期独立运行 | 通过：单人与双人物 30 天基准 |
| 人物具备自主生活、练习、目标与承诺 | 通过：59 次单人练习、长期目标达成、约定完成 |
| 多 NPC 可以实际互动、相互影响 | 通过：双人物 29 次社交，关系与记忆按事件变化 |
| 世界资源不因语言生成而改变 | 通过：模型提议权限测试与外部消息对照 |
| 行动需要时间且可中断 | 通过：计划中的练习在中途世界事件后被取消 |
| 世界认知有限且不会直接读全局库存 | 通过：可见角色视图、个人已知地图和库存隔离测试 |
| 失败不无条件回复成功 | 通过：短缺场景仍会进入危机，退避日志不爆炸 |
| 存档续跑结果可复现 | 通过：快照恢复与 30 组随机切分复现 |
| LLM 兼容接口可在本环境真实访问云服务 | **未验收**：外网不可达，只测试了 ScriptedBackend |
| 完全通用的大型人物社会 | **未实现**：仅支持有限规则下的最小多人模拟 |

## 判定

**作为“可运行、可理解、可持续迭代的虚拟人物研究基础工程”，验收通过。**

**作为“具备真实人类心理能力、支持复杂开放世界、可直接生产上线的通用虚拟人类系统”，尚未达到，不作此类保证。**
