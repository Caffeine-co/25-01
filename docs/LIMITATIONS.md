# 能力边界、尚未验证的部分与后续路线

## 当前真正已实现的范围

| 目标 | 当前实现程度 | 边界 |
|---|---|---|
| 世界事实与有限认知 | 可用 | 地点拓扑、设施、资源、局部道路；没有真实地理/物理模型 |
| 自主生活 | 可用（规则式） | 需求与兴趣驱动活动；人物自主目标较简单 |
| 行动执行与中断 | 可用 | 通用处理器、多人参与者占用；没有连续碰撞或真实物理 |
| 计划与承诺 | 部分 | 需求持续目标、约定期限、逐段移动；无通用 GOAP、复杂依赖计划 |
| 情绪与人格 | 部分 | 若干数值倾向、单次事件冲击、衰减；没有心理学标定 |
| 长期成长 | 部分 | 技能学习与长期阈值目标；人格、价值观未动态演化 |
| 记忆与信念 | 部分 | 有情景记忆、已知设施、消息来源；缺少事件语义整合、系统性遗忘、真正自传记忆 |
| 多 NPC 社会 | 部分 | 共享世界、可占用的社交、帮助、关系；缺少复杂对话内容与社会制度 |
| 真实 LLM 语言/建议 | 接口可用，在线未验 | 有合法性检查、预算、失败回退；远程 API 需用户环境验证 |
| 大规模/常驻运行 | 未实现 | 适用于小规模离线模拟；没有后台调度服务或生产级并发保障 |

## 为什么它还不是完整的“虚拟人类”？

1. **身体不具医学真实性**。`vitality`、口渴、疲劳、睡眠压力只是有限的模拟参数，不能推断病情、人体代谢或行为健康。不存在生理器官、损伤部位、治疗系统或死亡机制。
2. **人格不是完整的心理模型**。内外向、宜人性等参数仅在有限行为规则中产生倾向，缺少长期人格演化与不确定认知。
3. **长期计划仍很浅**。它能够保留需求目标、执行多段移动、履行简单承诺和达成技能阈值，却不会自行发明大型多周项目、分解复杂资源依赖或推导任意新行动类型。
4. **记忆与社会认知很浅**。人物可以记录自己见过的设施和事件，但不能凭有限规则可靠理解复杂人际话语、真正的常识或深层动机。现有检索仅为文本片段相关性，不是语义理解。
5. **对话不是系统的主驱动力**。没有启用 LLM 时人物会生活，但只能输出固定的离线应答；启用后单轮回复也不是持续的开放域多轮对话记忆管理器。
6. **世界和 NPC 规模有限**。资源没有物品归属、贸易、经济、法律和复杂环境生成。离散事件队列存于单进程中，连续状态每分钟积分，未做跨机器共享或高并发测试。

## 已发现、未做“假修复”的客观约束

资源耗尽时角色可能长期停滞，当前的规则不会凭空恢复水或食物。这不是凭空补充库存就能修复的 bug，而是世界缺少可行方案。应扩充世界生产、搜寻、交易或其他人物帮助机制后重新验证。

模型可能生成不准确、刻板或不符合人格的表达。当前仅验证其结构和世界权限，不保证文风与人设合适。需要真实模型测试、人工标注和反事实场景验证。

## 原分支关系与兼容性

参考分支：[`Caffeine-co/25-01/tree/world-preview`](https://github.com/Caffeine-co/25-01/tree/world-preview)，检查到的版本为 v0.5，Git Tree SHA 为 `5a1449861b56246c43e186b4d7e53443de626f47`。

开发环境当时无法通过 `git clone` 下载完整仓库，因此当前包是依据 GitHub 接口读取的源代码结构、核心实现和文档重新整理、改造的**独立后继工程**。它不包含原项目的完整 Git 历史，也不声称 byte-for-byte 的旧分支兼容。新版本可以按其提供的三层 JSON 结构重新定义已有世界；旧 SQLite 存档不能直接继续。若未来需要回合并回原仓库，应做逐文件合并和回归测试，而不是覆盖原分支。

## 下一阶段优先项

建议先完善通用 `Goal` / `Plan` 与行动依赖，再加入可信的多轮对话/记忆摘要和目标冲突评估，接着是更自然的 NPC 日程、关系与共同任务，最后才考虑更丰富的心理状态、复杂物理世界、大规模模拟或真实平台部署。

验收标准应保持：同一个角色经历足够长时间后，世界事实不矛盾、行动后果可解释、记忆可追溯、状态变化不过度自强化、资源与时间账目可核对。在这些基础上再讨论“像不像一个人”。
