# 适用范围与明确缺失

## 已适合使用

- 学习、研发和小规模游戏/故事/聊天工具的虚拟人物内核。
- 有限地图、多种定义好的动作和资源、几个至几十个人物的原型实验（性能请在目标设备单独测）。
- 本地离线仿真、单机 HTTP 适配第三方平台、角色记忆与受约束模型输出。
- 可追踪行动和事件、可重放逻辑实验、定期备份与恢复。

## 不应宣称已经实现

1. 人格/情绪/信任的医学或心理学有效性：当前参数是可解释的工程近似。
2. 真正泛化的 GOAP/HTN 或开放世界计划生成：只有显式定义的有限动作和项目步骤。
3. 主动外部信息获取、开放世界地图发现与完善的世界知识推理：个人认知主要是设施、路网及可记录命题。
4. 跨对话长期语义 RAG：当前只是有界情景记忆、词项重合和来源标记。
5. 拟真的完整 NPC 对话、独立语言意图协商：社会行为仍以结构化事件为核心；自然语言质量取决于模型。
6. 同时运行多世界或分布式集群：当前是单实例世界、每个数据库单主写者。
7. 高可用重启后真实时间补算：现有策略刻意不补算停机时间。
8. 外部平台消息发送的 exactly-once：服务只返回文字，没有内置 QQ/网页推送事务 outbox。
9. 完整个人数据治理方案：审计日志默认持续增长；真实应用需制定私隐与保留策略。
10. 第三方真实在线模型的实际 SLA、成本、延迟和厂商输出兼容性：本次只测试了本地模拟 HTTP 服务。

## 对正式使用的具体建议

- 严格区分“模型说过什么”和“世界实际发生了什么”。
- 单独保护数据库、密钥和原始用户消息。
- 将 HTTP 服务放在 localhost 后方，不直接公网明文暴露。
- 系统对重大事件、错误信息和异常状态的人工检查仍然必要。
- 增加新能力前先建立可复现测试，然后按实验结果迭代。
