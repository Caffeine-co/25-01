# 状态推演规则
## 时间
* 历史状态代表推演起点，目标时间代表本次状态需要连续推演到的客观时间
* `new_status.current_time`必须等于输入提供的目标时间
* 不得自行修改、补全、提前或延后目标时间
## 连续推演
* 状态更新不是重新生成一个“符合人物印象”的角色状态，而是：
  1. 历史状态
  2. 时间经过
  3. 已发生事件
  4. 得到新的当前状态
* 判断依据依次考虑：
  1. 角色明确事实以及不可随意改变的长期设定
  2. 当前明确发生的事件和客观条件
  3. 角色固定日程、个人规律和历史状态
  4. 时间经过产生的自然变化
  5. 最后才使用一般常识进行有限补全
* 一般社会作息不得直接覆盖角色自身规律
  * 例如不能仅根据“白天”、“学生”、“工作日”就直接确定正在上课
  * 也不能仅根据“深夜”就直接确定已经睡觉或非常困倦
## 状态守恒
* 没有充分变化依据的字段应保持上一状态，或仅发生与经过时间相匹配的自然变化
* 不得为了让状态显得丰富而主动制造变化
* 地点、活动、社会环境及其他明显变化必须能够由以下至少一种依据解释：
  * 已发生事件
  * 固定日程
  * 上一活动的自然后续
  * 足够长的时间经过
  * 其他明确上下文
* 不得虚构输入中没有发生的具体出行、交流、消费、工作、学习或人物互动作为状态变化理由
## 状态输出
* “只输出变化字段”仅限制最终输出形式，不代表只检查显著状态；每次推演必须先完整判断所有状态字段是否因时间经过、实际事件和当前上下文发生变化，再省略最终值未变化的字段
* 输出采用增量形式：
  * `new_status.current_time`必须始终输出，并等于输入提供的目标时间
  * `new_status.changes`只列出最终值相较历史状态确实发生变化的字段
  * 未发生变化的字段不得为了保持输出完整而重复输出
  * 不得因为采用增量输出而忽略本应发生的自然状态变化
  * 如果除了时间推进之外没有任何字段需要变化，`changes`输出空列表
* `changes`中的每个字段表示该字段在目标时间的最终值，而不是变化量
## 变化速度
* 短时间变量可以较快变化，例如：
  * 情绪
  * 疲劳
  * 饥饿
  * 注意力
  * 社交意愿
* 长期或稳定变量原则上保持上一值，例如：
  * 稳定人格
  * 长期价值倾向
  * 长期行为模式
* 只有存在明确且足够持续或重大的原因时，稳定变量才能发生小幅变化
* 所有变化幅度都应与时间长度和事件强度相匹配
## 最终检查
* 生成结果前检查以下是否能够同时成立：
  * 角色事实
  * 目标时间
  * 历史状态
  * 实际事件
  * 状态之间的因果关系
* 若一般常识与具体角色事实冲突，优先具体角色事实
