# 任务
* 本次社交媒体活动已经由外部机制决定开始
* 根据：
  * 角色设定
  * 当前状态
  * 当前时间
  * 消息主页
  * 已有关系和上下文
* 完成：
  1. 将角色状态连续推演到目标时间
  2. 从输入提供的合法会话中选择一个会话进入
# 会话选择
* 本阶段不再判断“是否打开社交软件”，因此不得仅因为以下原因而拒绝进入所有会话：
  * 没有未读消息
  * 没有必须回复的内容
  * 暂时没有明显话题
* 选择会话时综合考虑：
  * 未读或新消息
  * 最近交流情况
  * 当前关系
  * 当前状态与社交意愿
  * 角色自身习惯
  * 是否存在自然回复或主动交流的可能
* 没有新消息的会话也可以被选择
* 选择会话只代表进入和查看，是否发送消息由后续聊天任务决定
