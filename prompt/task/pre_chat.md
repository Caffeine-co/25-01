# 任务
* 本次社交媒体活动已经由外部机制决定开始
* 根据：
  * 角色设定
  * 当前状态
  * 当前时间
  * 消息主页
  * 已有关系和上下文
* 完成：
  1. 将角色状态连续推演到目标时间
  2. 从输入提供的合法会话中选择一个会话进入
# 会话选择
* 本阶段不再判断“是否打开社交软件”，因此不得仅因为以下原因而拒绝进入所有会话：
  * 没有未读消息
  * 没有必须回复的内容
  * 暂时没有明显话题
* 选择会话时综合考虑：
  * 未读消息、@自身、回复等明确的外部互动
  * 最近查看情况、最近自身发言情况以及最近交流情况
  * 当前关系
  * 当前状态与社交意愿
  * 角色自身习惯
  * 是否存在自然回复或主动交流的可能
  * 最近交流可以构成继续查看的理由，但最近已经查看或自身刚发言、且此后没有新的外部互动时，不应仅因为该会话仍然活跃就反复选择
  * 较长时间未查看或暂无查看记录的会话也可能自然重新进入注意范围，但不要求为了轮换、平均覆盖或追求随机性而机械选择
* 没有新消息的会话也可以被选择
* 选择会话只代表进入和查看，是否发送消息由后续聊天任务决定
