# 任务
* 根据每个用户已有的完整用户画像、长期记忆、尚未归档的事件印象，模拟长期记忆整理过程，并输出归档后的完整用户画像、完整长期记忆集合
* 输出的`memory`是归档完成后的完整结果，不是本次新增记忆的增量
* 对输入提供的每个用户必须输出且只能输出一次，不得新增、遗漏或重复用户
* 对所有用户统一使用以下记忆整理标准，不得因模型自身偏好、输出篇幅或不同用户而临时改变保留尺度
# 基本原则
* 长期记忆不是聊天记录的永久副本，应优先保留事件的核心意义、稳定事实及对未来互动仍有价值的信息
* 具体事件随着时间和后续经验可以逐渐失去无关细节，并被压缩、合并为更概括的长期认知，但重要事件本身仍可作为具体事件记忆长期存在
* 时间只能作为记忆整理的辅助因素：
  * 不得仅因记忆较早而删除仍然重要的信息
  * 不得仅因事件刚发生就自动认为值得进入长期记忆
* 重复出现或在不同时间被再次支持的信息具有更高的巩固价值，但同一次事件被重复提及不等于多个独立证据
* 情绪强度、关系意义和角色自身关注程度可以提高事件的保留倾向，但不能提高其中事实的可信度，也不能作为推断用户稳定特征的证据
* 不确定时：
  * 在“保留核心信息”与“完全删除”之间，优先保留或压缩核心信息
  * 在“形成稳定画像”与“仅保留事件记忆”之间，优先仅保留事件记忆
  * 不得通过猜测补全缺失信息
# 角色视角
* 角色设定只影响对事件重要性、关注角度、情绪或关系意义以及未来互动价值的判断，不改变事件事实本身
* 不得因为角色具有某种喜好、经历、观点或性格，就推断用户具有对应特征；用户事实只能来源于输入提供的画像、记忆或事件印象
# 固定证据标准
* 单次事件可以形成重要的具体事件记忆，但不得仅凭一次行为、情绪、选择或玩笑概括用户稳定特征
* 用户明确表达且本身具有长期或稳定含义的自身事实，一次清晰且无矛盾的表达即可作为长期事实记忆，并可据此更新用户画像
* 从行为归纳规律时：至少2个不同事件中的独立证据才能形成“反复出现的倾向或模式”长期记忆；至少3个独立证据、且分布在至少2个不同时间或情境中，才能进一步形成用户画像中的稳定特征
* 同一事件被再次提及可以提高其保留价值，但不增加独立证据数量；存在明确反例或矛盾时，不得仅靠达到次数形成稳定特征
# 记忆整理顺序
对每一条已有长期记忆和新的事件印象，统一按照以下顺序处理：
## 1. 判断事实来源
* 只处理输入中实际存在的信息
* 区分：
  * 用户明确说明的事实
  * 角色亲历的共同事件
  * 从多次事件中归纳出的模式
  * 角色自身的主观感受或关系体验
* 不得把推测重新写成确定事实
## 2. 判断长期价值
优先保留下列信息：
* 用户明确且仍然有效的长期事实、偏好、习惯、身份背景、现实约束和长期目标
* 对未来互动仍可能产生直接影响的事实
* 尚未完成的约定、承诺、计划或具有后续意义的事项
* 对双方关系产生明显变化或持续影响的重要事件
* 对角色具有明显情绪或关系意义的重要共同经历
* 在多个独立事件中重复出现的重要主题、行为模式或长期倾向
* 即使时间较早，仍然具有身份、关系、承诺或长期解释价值的信息
## 3. 巩固与抽象
* 多个独立事件反复支持同一事实或模式时，应减少重复事件堆积，并提取其中稳定的共同核心
* 巩固后的内容应描述被多个事件共同支持的事实或规律，不得扩大到证据没有支持的范围
* 两次独立出现只能支持“曾多次出现”“存在这种倾向”等有限概括，不得自动升级为稳定人格
* 只有达到“固定证据标准”的信息才能进入用户画像
* 如果某个具体事件本身具有明显关系意义、情绪意义或独特性，即使其一般规律已经被巩固，该事件仍可以作为独立的重要事件记忆保留
## 4. 细节压缩
* 对仍值得保留的具体事件，优先保留：
  * 发生了什么
  * 与谁相关
  * 对双方关系、后续互动或用户认知产生了什么重要影响
  * 必要的时间和来源信息
* 可以逐渐删除：
  * 与事件意义无关的措辞细节
  * 无后续影响的过程细节
  * 已被核心结论完整涵盖的重复描述
* 事件越普通、越缺乏后续意义，其长期记忆越应偏向核心概括而非完整细节
* 情绪强烈并不意味着必须永久保留所有现场细节，应优先保留造成情绪或关系意义的核心原因
## 5. 更新与冲突
* 新的明确事实清楚修正或取代旧事实时，以新的明确事实更新对应长期记忆
* 用户明确纠正此前信息时，明确纠正优先于此前推测、归纳或旧信息
* 暂时状态不得自动覆盖长期事实，例如一次心情、一次临时安排不得直接取代长期偏好或长期习惯
* 如果新旧信息体现了具有长期意义的真实变化，可以保留“发生了变化”这一事实
* 如果新旧信息存在无法判断的矛盾：
  * 不得擅自选择更符合常识或角色预期的一方
  * 不得将其中任何一方写入用户画像作为确定特征
  * 必要时将矛盾本身以不确定形式保留在长期记忆中
## 6. 淘汰
### 满足以下条件的信息可以淘汰：
* 单次出现且普通、琐碎，对未来互动没有明显价值
* 临时情绪、临时状态、临时话题，且没有形成后续影响
* 已经被更高层次长期记忆完整概括，单独保留不再提供额外信息
* 与其他记忆语义重复，仅是不同措辞
* 已被新的明确事实完全取代，且旧状态本身没有关系或历史意义
* 大量相似事件中的普通重复项，其共同规律已经得到可靠巩固
### 不得仅因为以下原因淘汰记忆：
* 时间较早
* 最近没有再次谈起
* 内容较短
* 当前一次互动没有使用到该记忆
# 时间与来源字段
* `memory`仍然是具有来源和时间的长期事件记忆集合，不得虚构来源或时间
* 保留某一具体事件时：
  * 保持该事件原有的`type`、`group_id`（如有）和`time`
* 多个事件被巩固为一条长期记忆时：
  * 使用最近一次实际支持该巩固结果的事件的`type`、`group_id`（如有）和`time`
  * `content`写多个事件共同支持的核心内容
  * 不得把归档时间作为事件发生时间
* 新事件明确更新旧记忆时：
  * 使用造成这次更新的最新明确事件的来源和时间
* 已有巩固记忆没有得到新的独立证据时，不得仅因再次归档而修改其时间
* 最终`memory`必须按照`time`从早到晚排序
# 用户画像
* 用户画像表示角色目前对该用户形成的稳定、简洁的长期认知，不是聊天历史摘要，也不是事件记忆列表
* 用户画像必须以归档完成后的长期记忆为依据
* 可以进入画像的信息仅包括：
  * 用户明确说明且具有长期稳定含义的事实
  * 达到固定证据标准的稳定偏好、习惯、行为倾向或长期特征
  * 对理解用户具有持续意义的身份背景、长期目标和现实约束
* 单次情绪、行为、选择、玩笑、临时状态或话题，以及单个事件中的角色主观印象，不得直接写成稳定画像
* 证据不足或仍存在明显矛盾的特征不得写成确定画像
* 画像描述当前仍成立的稳定认知，已经明确失效的旧特征应更新或移除
* 画像应保持简洁，不重复罗列已经存在于事件记忆中的具体过程
# 去重
* 最终长期记忆集合不得存在语义重复；同一事件被多次提及不得生成多个记忆，多个低层事件可靠巩固后，无额外关系、情绪或事实价值的重复项可以删除
* 重要、独特且具有额外关系意义的具体事件，即使部分意义已经被高层记忆概括，也允许继续独立保留
# 输出检查
输出前逐个用户检查：
* 是否完整处理已有`memory`和新的`impression`，且没有新增输入中不存在的事实
* `portrait`是否只包含达到固定证据标准、当前仍成立且无明显矛盾的稳定认知
* `memory`是否完成去重、巩固、必要淘汰，同时没有仅因时间较早而删除重要信息
* 所有记忆的来源、时间是否符合规则，最终结果是否为完整集合并按时间先后排序
