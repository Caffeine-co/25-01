# 任务
* 根据每个用户已有的完整用户画像、长期记忆、尚未归档的事件印象，模拟长期记忆整理过程，并输出归档后的完整用户画像、完整长期记忆集合
* 输出的`memory`是归档完成后的完整结果，不是本次新增记忆的增量
* 对输入提供的每个用户必须输出且只能输出一次，不得新增、遗漏或重复用户
# 角色视角
* 角色设定用于判断：
  * 哪些事件自身更加关注
  * 哪些事情具有情绪或关系意义
  * 哪些信息值得长期记住
  * 不同事件在角色主观上的重要程度
* 角色特征只能影响记忆的重要性、关注角度与保留倾向
* 不得因为角色自身具有某种喜好、经历、观点、性格，就推断用户也具有对应特征
* 用户事实必须来源于实际提供的用户信息
# 记忆整理
* 对已有长期记忆和新的事件印象进行整体重新整理
* 允许进行：
  * 保留
    * 继续保留对未来互动仍然有明显意义的信息，例如：
      * 长期偏好
      * 重要经历
      * 关系变化
      * 重要共同事件
      * 长期习惯
      * 明确承诺
      * 经常重复出现的重要主题
  * 巩固
    * 多个相关事件反复支持同一长期事实时，可以合并为更稳定、简洁的长期记忆
    * 不得仅因为一次事件就过度概括稳定特征
  * 更新
    * 如果新的明确事实修正或取代已有旧事实，可更新相应记忆
    * 新旧信息存在无法确定的矛盾时，不得擅自选择更符合常识的一方
  * 压缩
    * 高度重复、意义相近的长期记忆应合并，避免同一事实不断累积不同措辞版本
  * 淘汰
    * 长期没有再次出现、未来互动价值很低、内容琐碎且缺乏关系意义的事件允许逐渐淘汰
    * 不得单纯因为记忆时间较早就删除仍然重要的信息
# 用户画像
* 用户画像是当前长期认知的简洁总结，不是聊天历史摘要
* 应根据归档后的长期记忆更新
* 只有得到足够证据支持的稳定特征才能进入画像
* 不得将以下内容直接概括为稳定人格：
  * 单次情绪
  * 一次行为
  * 临时话题
  * 一次玩笑
# 去重
* 新的完整长期记忆集合内部不得存在语义重复条目
* 已经被更高层次记忆完整概括、且单独保留没有额外价值的低层事件可以被合并或淘汰
